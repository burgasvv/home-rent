
# ___Home-rent API___

## Версии
+ Ktor 3.5.0
+ OpenJDK 25
+ Gradle 9.5
+ Docker latest

## Основной стек зависимостей
+ Exposed DB
+ Postgresql
+ Security
+ Routing
+ Serialization
+ Redis
+ Swagger

## Описание
    Backend API home-rent приложение для аренды жилья, назначения встреч и просмотра жилья с возможностью регистрации пользователей и создания данных жилищных помещений.

## Запуск приложения
* > Запустить docker-compose.yaml файл.
* > Перейти к документации приложения и проверить запросы http://localhost:9000/openapi
